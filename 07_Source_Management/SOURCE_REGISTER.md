# 1. Purpose

This document is the master registry of information sources used by the
Mechanical Services Supervisor Intelligence System.

Its purpose is to provide:

-   Source traceability.
-   Document ownership awareness.
-   Verification tracking.
-   Knowledge governance.
-   Transparency regarding information origins.

Every important piece of guidance should be connected to an identifiable
source.

------------------------------------------------------------------------

# 2. Source Management Principles

The system follows these principles:

> **Know where information comes from.**

> **Distinguish source material from interpretation.**

> **Verify important information regularly.**

> **Never treat outdated information as current without confirmation.**

> **A trustworthy AI system requires trustworthy sources.**

# 10. Source Verification Rules

Before providing guidance, Claude should consider:

1.  Is there an applicable source?
2.  Is the source current?
3.  Does the source apply to this situation?
4.  Does another source override it?
5.  Is consultation required?

------------------------------------------------------------------------

# 11. Source Priority Hierarchy

When sources conflict, generally prioritize:

1.  Legislation and regulatory requirements.
2.  University policies.
3.  Collective agreement obligations.
4.  Safety requirements.
5.  Department procedures.
6.  Internal guidance frameworks.
7.  General best practices.

------------------------------------------------------------------------

# 12. Source Update Process

When a source changes:

1.  Update the affected document.
2.  Record the change in `CHANGELOG.md`.
3.  Update `POLICY_MANIFEST.json`.
4.  Update `LAST_VERIFIED.md`.
5.  Review affected guidance.

------------------------------------------------------------------------

# 13. Final Statement

A strong AI knowledge system is built on accountability to its sources.

The question is not only:

> "Does Claude know the answer?"

The better question is:

> "Can Claude explain where that answer came from?"

Source awareness creates trust.

That is knowledge becoming architecture.
