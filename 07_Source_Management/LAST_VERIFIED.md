-   Verification protects accuracy.

# 8. Claude Verification Behaviour

Before providing policy-related guidance, Claude should consider:

1.  Is the relevant source identified?
2.  Is the source current?
3.  Has the source changed recently?
4.  Does the local document reflect the current source?
5.  Is additional verification required?

If uncertainty exists:

-   Identify the uncertainty.
-   Avoid overstating confidence.
-   Recommend appropriate verification.
